# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of VCX-Knob Home Assistant integration
- BLE device discovery and connection
- 13 sensor entities for monitoring device state
- 11 switch entities for on/off control
- 7 select entities for multi-option settings
- 3 button entities for one-time actions
- 1 binary sensor for connection status
- Bilingual support (English and Simplified Chinese)
- Auto-reconnection on disconnect
- Service for sending raw commands to device
- Comprehensive documentation

## [1.0.0] - 2024-XX-XX

### Added
- Initial release
- Full BLE protocol implementation for VCX-Knob devices
- Config flow with device scanning
- All entity types (sensors, switches, buttons, selects, binary sensors)
- Internationalization support
- Auto-reconnection functionality
- Custom service for raw command sending
