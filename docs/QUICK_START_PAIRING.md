# VCX-Knob 快速配对指南

## 你的问题：按钮显示为灰色

### 原因
设备已**连接**但未**配对**。配对是必需的，用于获得写入控制权限。

---

## 解决方法（按推荐顺序）

### 方法 1：Home Assistant 界面配对 ⭐ 推荐

1. **设置** → **设备与服务**
2. 点击 **添加集成** → 搜索 **Bluetooth** → 添加
3. 点击 Bluetooth 集成 → **配置**
4. 点击 **扫描设备**
5. 找到 VCX-Knob → 点击 **配对**
6. 输入 PIN（如果需要）：`0000` 或 `1234`
7. 配对成功后，重新添加 VCX-Knob 集成

---

### 方法 2：手机蓝牙配对 ⭐ 最简单

1. 打开手机蓝牙设置
2. 找到 VCX-Knob 设备
3. 点击配对
4. 完成！（配对信息会自动同步）

---

### 方法 3：命令行配对（高级）

```bash
# 在 Home Assistant 服务器上执行
bluetoothctl
scan on
# 记下 VCX-Knob 的 MAC 地址
pair 88:36:A2:D8:80:AC
# 在设备上确认配对
trust 88:36:A2:D8:80:AC
info 88:36:A2:D8:80:AC
# 应该显示 Paired: yes
quit
```

---

## 验证配对成功

✅ **成功标志**：
- Home Assistant 中的按钮**不再是灰色**
- 可以成功点击按钮并看到设备响应

❌ **失败标志**：
- 按钮仍然是灰色
- 日志显示 `[org.bluez.Error.NotPermitted] Write not permitted`

---

## 常见 PIN 码

- `0000`
- `1234`
- `8888`
- 查看设备说明书

---

## 不需要配对的情况

如果你已经可以通过其他方式控制设备（如微信小程序），说明设备已经与某个手机配对。蓝牙设备通常只能与一个设备主动配对。

**解决方案**：
1. 在原配对设备上取消配对
2. 然后在 Home Assistant 中重新配对

---

## 仍然无法配对？

1. **检查距离**：将设备靠近 Home Assistant 服务器（1 米以内）
2. **检查设备模式**：设备可能需要进入配对模式（查看说明书）
3. **重启蓝牙**：
   - 设置 → 系统 → 硬件
   - 找到蓝牙适配器 → 重新加载
4. **查看设备说明书**或联系厂商
