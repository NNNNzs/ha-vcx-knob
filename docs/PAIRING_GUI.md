# VCX-Knob 配对指南 - Home Assistant UI 方法

## 最简单的方法：使用 Home Assistant 界面配对

### 步骤 1：添加蓝牙集成

1. 打开 Home Assistant
2. 前往 **设置 → 设备与服务**
3. 点击 **添加集成** ➔
4. 搜索并添加 **Bluetooth** 集成

### 步骤 2：配对 VCX-Knob 设备

在蓝牙集成页面中：

1. 找到并点击 **Bluetooth** 集成
2. 点击 **配置** 按钮
3. 点击 **扫描设备**
4. 在设备列表中找到 **VCX-Knob**
5. 点击设备右侧的 **配置** 或 **配对** 按钮
6. 如果提示输入 PIN 码，尝试常见密码：
   - `0000`
   - `1234`
   - `8888`
   - 查看设备说明书

### 步骤 3：验证配对

配对成功后：
- 设备应该显示为 "已配对" 状态
- 在蓝牙设备列表中能看到 VCX-Knob

### 步骤 4：添加 VCX-Knob 集成

配对完成后，添加集成：
1. 前往 **设置 → 设备与服务**
2. 点击 **添加集成** ➔
3. 搜索 **VCX-Knob**
4. 选择你的设备
5. 完成配置

### 如何确认配对成功？

#### 方法 1：在蓝牙集成中查看
- 设备状态显示 "已连接" 或 "Connected"
- 没有显示 "未配对" 错误

#### 方法 2：测试实体
- VCX-Knob 集成中的按钮**不是灰色**
- 可以成功点击按钮并看到设备响应

#### 方法 3：检查日志
前往 **设置 → 系统 → 日志**，搜索 "vcx_knob"
- ✅ 配对成功：无 "Write not permitted" 错误
- ❌ 未配对：显示 `[org.bluez.Error.NotPermitted] Write not permitted`

## 常见问题

### Q: Bluetooth 集成显示 "未找到设备"？

A: 确保：
- VCX-Knob 设备已开机
- 设备在蓝牙范围内（通常 10 米以内）
- Home Assistant 的蓝牙适配器正常工作

### Q: 配对时提示 "连接失败"？

A: 尝试：
1. 将设备靠近 Home Assistant 服务器（1 米以内）
2. 在设备上进入配对模式（查看设备说明书）
3. 重启 Home Assistant 的蓝牙适配器：
   - 设置 → 系统 → 硬件
   - 找到蓝牙适配器，点击 **重新加载**
   - 或重启 Home Assistant

### Q: 配对成功后，按钮还是灰色？

A: 可能原因：
1. 设备未连接（检查 "已连接" 二进制传感器）
2. 蓝牙写入权限问题（尝试重新配对）
3. 设备固件问题（联系厂商）

### Q: 我不想用 HA UI，还有其他方法吗？

A: 有的，你可以：
1. **使用手机蓝牙配对**（最简单）- 配对信息会自动同步
2. **使用命令行** - 在宿主机上执行 `bluetoothctl pair <MAC>`
3. **使用配对脚本** - 运行 `pair_device.sh` 自动配对

## 配对后的好处

配对成功后，你将获得：
- ✅ 完整的设备控制权限
- ✅ 按钮可以正常点击（不再是灰色）
- ✅ 开关、选择器等控制实体可以正常工作
- ✅ 自动重连功能正常工作

## 配对只需要一次

配对信息会永久保存在系统中：
- 如果使用 HA UI 配对，信息保存在蓝牙数据库中
- 重启 Home Assistant 不会影响配对状态
- 只需要配对一次，以后会自动连接

## Docker 用户的注意事项

即使 Home Assistant 运行在 Docker 容器中：
- **推荐**：在 HA UI 中配对（最简单）
- **可选**：在宿主机上用 `bluetoothctl` 配对
- **不需要**：进入容器内部配对

因为容器的蓝牙系统与宿主机共享，在宿主机上配对后，容器内的 Home Assistant 可以直接使用。
